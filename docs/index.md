**8bot for VS Code** is an open source AI coding agent and chat for Visual Studio Code, powered by your Pax8 8os Agent Gateway and API key. It can read your code, edit files and run commands, with you deciding how much it may do on its own.

*Independent project. Not affiliated with or endorsed by Pax8.*

[Get the code on GitHub](https://github.com/upggr/8bot-vscode) · [Get an 8os subscription](https://buy-it.gr/8os)

## What you can do

- Chat with your code in a dedicated sidebar with streaming replies and saved history
- Use `@8bot` in the VS Code Chat window
- Add 8os models to the VS Code Chat model picker
- Let the agent create and edit files, with a diff preview, and run terminal commands
- Select any model your 8os key can use, including automatic routing
- Choose a permission mode: Ask first, Accept edits, Plan only or Bypass permissions
- See the cost of each request, your monthly spend and your remaining credits
